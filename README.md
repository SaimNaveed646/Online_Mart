# Online Shopping Project (Python)
## Project Description

This is a basic Online Shopping project developed using Python as a first learning project.
The main goal of this project is to understand and apply basic Python functionalities in a real-life scenario.
The project demonstrates a simple online shopping system and uses core Python concepts such as:

Variables and data types
Conditional statements
Loops
Functions
Basic data handling


## Technologies Used

Python
Python built-in functions and basic features

## Purpose

The purpose of this project is to practice Python programming fundamentals and gain hands-on experience by implementing a real-world example of an online shopping system.
